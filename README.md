# SubPanel

Панель для Premiere Pro и After Effects (CEP, одна на обе программы): заготовки стиля субтитров и удаление знаков препинания.

## Установка

1. Закрой Premiere Pro и After Effects.
2. Запусти `dist/SubPanel-Setup.exe` (права администратора не нужны).
3. Открой программу: **Окно → Расширения → SubPanel**.

Установщик копирует панель в `%APPDATA%\Adobe\CEP\extensions\com.fersiya.subpanel` и включает `PlayerDebugMode` (без него Adobe не загружает неподписанные панели).

## Что умеет

- **Заготовки**: шрифт, размер, заливка, обводка, регистр, позиция. Свои заготовки сохраняются кнопкой «+ Сохранить».
- **Убрать знаки**: `. , ! ? …` по умолчанию, остальные знаки включаются отдельно.

| | After Effects | Premiere Pro |
|---|---|---|
| Стиль | текстовые слои: шрифт, размер, цвет, обводка, регистр, позиция | графические клипы (текст/MOGRT): шрифт и размер |
| Убрать знаки | выделенные текстовые слои (или все, если ничего не выделено), в том числе текст по ключам | графические клипы; для подписей (Captions) — через буфер обмена или SRT-файл |

В Premiere подписи (Captions) скриптам недоступны: Adobe не даёт читать и менять их текст ни через ExtendScript, ни через UXP. Поэтому для них:

1. **Из буфера обмена**: выдели текст в панели «Текст», Ctrl+C, нажми кнопку, затем Ctrl+V.
2. **SRT-файл**: панель сохраняет рядом `имя.clean.srt` и пытается добавить его в секвенцию.

## Сборка

```bash
./build.sh   # нужен makensis (apt install nsis)
```

Результат: `dist/SubPanel-Setup.exe`.

## Удаление

«Параметры → Приложения → SubPanel» или `Uninstall.exe` в папке панели.
