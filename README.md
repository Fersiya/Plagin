# SubPanel & Adobe Studio Suite v1.5.0

Комплексный набор профессиональных инструментов для монтажеров и моушн-дизайнеров в **Adobe Premiere Pro** и **Adobe After Effects**: расширение **SubPanel** с живым **AI Bridge**, умными инструментами монтажа (Punch-In, бит-маркеры, SFX) + автономный лаунчер **Adobe Studio Launcher** со встроенным конвертером **ProRes Proxy** и сортировщиком съемок.

Поддерживаются версии **Adobe CC 2019 — 2026+**.

---

## ⚡ Что нового в v1.5.0:

### 1. 🤖 Прямой AI Bridge (Antigravity ↔ Premiere Pro / After Effects)
* **Встроенный локальный сервер**: при открытии панели SubPanel в Premiere Pro или After Effects автоматически стартует локальный HTTP / JSON-RPC сервер на `http://127.0.0.1:8999`.
* **Прямое управление из чата и терминала**: AI-агенты Antigravity, внешние скрипты или CLI-утилита `scripts/adobe_bridge.py` могут напрямую отдавать команды в таймлайн Adobe:
  * Получение статуса открытого проекта (`/status`)
  * Исполнение любого ExtendScript кода на лету (`/eval`)
  * Автоматическая расстановка маркеров по таймлайну (`/markers`)
  * Применение авто-зумов и плашек (`/punchin`, `/action`)
* **Визуальный индикатор в панели**: бейдж `🟢 AI: 8999` в шапке панели показывает статус соединения. Клик по бейджу копирует адрес моста в буфер обмена.

### 2. 🎬 Умные инструменты монтажа (Монтаж и AI):
* **🔍 Динамический Punch-In авто-зум**:
  * Специально для вертикального контента (Shorts / Reels / TikTok): кнопка «🔍 Punch-In зум» автоматически чередует масштаб (100% ↔ 115%) каждые 3 секунды. Сбрасывает усталость зрителя и удерживает внимание без ручной нарезки.
* **🎵 Бит-маркеры (Beat Sync)**:
  * В 1 клик расставляет ритмические маркеры на таймлайне Premiere Pro и композиции After Effects под темп музыки, позволяя нарезать видео строго под бит с привязкой курсора (`S`).
* **✂️ Авто-нарезка пауз и тишины (Jump-Cut Detection)**:
  * Консольная утилита `adobe_bridge.py silence` через FFmpeg анализирует звуковую дорожку диктора, находит паузы длиннее $N$ миллисекунд и передает отметки резов прямо в секвенцию.
* **💨 Быстрые звуковые маркеры (SFX Quick-Drop)**:
  * Кнопки мгновенных меток под курсор: *Вжух*, *Поп*, *Клик*, *Райзер*, *Дроп*.

### 3. 🛠 Медиа-инструменты в Adobe Studio Launcher:
* **▶ Быстрый генератор монтажных ProRes Proxy**:
  * В окне лаунчера кнопка «Медиа-инструменты...» позволяет выбрать тяжелое 4K / H.265 видео и в 1 клик через FFmpeg сжать его в плавный Apple ProRes Proxy (720p). Монтаж не тормозит даже на слабых ноутбуках!
* **📁 Авто-сортировщик съемок с SD-карты**:
  * Выбираешь папку со съемочным материалом — утилита мгновенно раскладывает файлы:
    * `01_RAW` — видеофайлы (`.mp4`, `.mov`, `.mkv`, `.braw`, `.avi`)
    * `02_AUDIO` — звук с микрофонов и рекордера (`.wav`, `.mp3`, `.m4a`)
    * `03_ASSETS` — графика и фото (`.png`, `.jpg`, `.psd`, `.ai`)

## ⚡ Adobe Studio Launcher

Автономная утилита (чистый C# .NET, запускается мгновенно без установки из любой папки):
- **Поддержка Premiere Pro (`.prproj`) и After Effects (`.aep`)** в одном окне с бейджами `Pr` (фиолетовый) и `Ae` (синий).
- **Вкладки фильтрации**: переключение между `[ Все ]`, `[ Premiere Pro ]` и `[ After Effects ]` с живым счётчиком.
- **⏱ Восстановление из автосохранений (Auto-Save Recovery)**: просмотр и откат ревизий с созданием резервной копии `.backup`.
- **📁 + Проект со структурой**: создание папок `01_RAW`, `02_AUDIO`, `03_ASSETS`, `04_PROJECT`, `05_EXPORTS` в 1 клик.
- **Перетаскивание (Drag & Drop)**: перетащи любой проект в окно лаунчера для закрепления.
- **🧹 Единая очистка кэша Adobe CC**: удаление гигабайтов временных файлов Media Cache и After Effects Disk Cache.

## 🎨 SubPanel: Возможности панели

- **📦 Авто-плашка под текст (AE Auto-Box)**: шейповая подложка с динамическим выражением `sourceRectAtTime()` — автоматически меняет размер при наборе текста.
- **🎯 Центр Anchor Point (AE Center Anchor)**: центрирование якорной точки строго по центру букв.
- **🧹 Очистка RAM и дискового кэша (AE Purge)**: мгновенный сброс памяти `app.purge(ALL_CACHES)`.
- **🎬 1-клик анимации текста (AE)**:
  - *Машинка (Typewriter)* с мигающим курсором `|`
  - *Кинематографичный Блюр (Blur Fade)*
  - *Pop-Up (Отскок)* и *Fade Up*
  - *Wiggle* и *Сброс*
- **✍️ Умный русский типограф**:
  - Замена дефисов на длинные тире `—` (включая диалоги в начале строк).
  - Замена кавычек на русские «ёлочки».
  - Замена многоточий `...` на `…`.
  - Неразрывные пробелы `\u00A0` после коротких предлогов и союзов (`в`, `на`, `с`, `и`, `к`, `от`, `по`, `из`...).
- **Заготовки стиля субтитров**: встроенные стили (*Классика*, *Шортс*, *МистерБист*, *ТикТок*, *Неон*, *Кино*, *Караоке*, *Минимал*), сохранение своих заготовок, импорт и экспорт в JSON.
- **Конвертер регистров**: Обычный, `ВСЕ ЗАГЛАВНЫЕ`, `Как в предложениях.`, `Каждое Слово С Заглавной`, `строчные`.
- **Цензура мата (1-Click)**: замена нецензурных слов на `***` или `@#$%`.
- **Очистка знаков препинания**: выборочное или полное удаление знаков.

## 💻 Использование AI Bridge через Python CLI

В проект входит CLI-клиент `scripts/adobe_bridge.py`:

```powershell
# 1. Проверить подключение к Premiere Pro / After Effects
python scripts/adobe_bridge.py status

# 2. Выполнить произвольный ExtendScript код
python scripts/adobe_bridge.py eval "app.project.activeSequence.name"

# 3. Расставить бит-маркеры на таймлайне
python scripts/adobe_bridge.py markers --times "1.5, 3.0, 4.5, 6.0" --name "Beat"

# 4. Применить Punch-In зум
python scripts/adobe_bridge.py punchin --interval 3.0 --scale 115

# 5. Найти паузы/тишину в звуковой дорожке и отправить маркеры резов
python scripts/adobe_bridge.py silence --audio "voiceover.wav" --threshold -30 --send

# 6. Создать быстрый ProRes Proxy для видео
python scripts/adobe_bridge.py proxy --input "C:/Footage/raw_4k.mp4"
```

## 🚀 Установка

1. Скачайте инсталлятор **`SubPanel-Setup.exe`** из раздела [Releases](https://github.com/Fersiya/Plagin/releases).
2. Запустите установку (права администратора не требуются):
   - Установит панель **SubPanel** в `%APPDATA%\Adobe\CEP\extensions\com.fersiya.subpanel`.
   - Установит **Adobe Studio Launcher** (`PrLauncher.exe`) и создаст ярлыки на Рабочем столе и в меню «Пуск».
   - Автоматически настроит `PlayerDebugMode` для CSXS 9–20 в реестре Windows.
3. Откройте Premiere Pro или After Effects: меню **Окно → Расширения → SubPanel**.
4. Для мгновенного открытия проектов используйте ярлык **Adobe Studio Launcher** на рабочем столе.
