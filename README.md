# SubPanel

Панель для Premiere Pro и After Effects (CEP, одна на обе программы): заготовки стиля субтитров и удаление знаков препинания.

Поддерживает версии Adobe CC 2019 — 2026+.

## Установка

1. Закрой Premiere Pro и After Effects.
2. Запусти `dist/SubPanel-Setup.exe` (права администратора не нужны).
3. Открой программу: **Окно → Расширения → SubPanel**.

Установщик копирует панель в `%APPDATA%\Adobe\CEP\extensions\com.fersiya.subpanel` и включает `PlayerDebugMode` для CSXS 9–20 (без него Adobe не загружает неподписанные панели).

## Что умеет

- **Заготовки стиля**:
  - Встроенные пресеты: *Классика*, *Шортс*, *МистерБист*, *ТикТок*, *Неон*, *Кино*, *Караоке*, *Минимал*.
  - Настройка параметров: шрифт (PostScript-имя с поиском из установленных), размер, цвет заливки, цвет и толщина обводки, выравнивание текста (Слева / По центру / Справа), межзнаковый интервал (Tracking), ВСЕ ЗАГЛАВНЫЕ, позиция по высоте.
  - Сохранение своих заготовок кнопкой «+ Сохранить».
  - Экспорт и импорт пользовательских заготовок в JSON-файл для удобного обмена с коллегами или переноса между ПК.
  - Опция «Применять сразу при клике».
- **Удаление знаков препинания**:
  - Символы: `. , ! ? … : ; — - " «» ' ( ) [ ]`.
  - Кнопки быстрого выбора: «Все» и «Сброс» (к базовым знакам).
  - Удаление многоточий (`...`), кавычек, скобок и диалоговых тире в начале строк.

| | After Effects | Premiere Pro |
|---|---|---|
| Стиль | текстовые слои: шрифт, размер, цвет, обводка, выравнивание, трекинг, регистр, позиция (включая слои с разделёнными координатами) | графические клипы (текст/MOGRT): шрифт, размер, выравнивание, регистр |
| Убрать знаки | выделенные текстовые слои (или все в композиции, если ничего не выделено), включая слои с ключами | выделенные клипы или все клипы активной секвенции; для подписей (Captions) — через буфер обмена или SRT-файл |

В Premiere подписи (Captions) скриптам напрямую недоступны (Adobe не даёт читать и менять их текст ни через ExtendScript, ни через UXP). Поэтому для них предусмотрено два удобных пути:

1. **Из буфера обмена**: выдели текст в панели «Текст», нажми Ctrl+C, нажми кнопку «Из буфера обмена» в SubPanel, затем нажми Ctrl+V.
2. **SRT-файл**: нажми «SRT-файл», выбери исходный `.srt`, панель сохранит рядом `имя.clean.srt` и автоматически импортирует и добавит дорожкой подписей в секвенцию.

## Обновления

При открытии панель проверяет последний релиз на GitHub. Если вышла новая версия, сверху появится плашка с кнопкой «Обновить»: панель скачивает `SubPanel-Setup.exe` из релиза, проверяет его и тихо ставит в фоне. После этого достаточно перезапустить Pr/AE.

Чтобы выпустить обновление вручную:
1. Подними версию в `js/main.js`, `CSXS/manifest.xml` и `installer/installer.nsi`.
2. Выполни сборку через `./build.ps1` (на Windows) или `./build.sh` (на Linux/macOS). Скрипт проверит, что версии совпадают во всех трёх файлах.
3. Создай на GitHub релиз с тегом `vX.Y.Z` и приложи `dist/SubPanel-Setup.exe`.
*(Также настроен GitHub Actions CI, который автоматически собирает и публикует релиз при создании тега `v*`)*.

## Сборка

### Windows (PowerShell):
```powershell
./build.ps1
```

### Linux / macOS / Git Bash:
```bash
./build.sh   # нужен makensis (apt install nsis или brew install makensis)
```

Результат сборки: `dist/SubPanel-Setup.exe`.

## Удаление

«Параметры Windows → Приложения → SubPanel» или запусти `Uninstall.exe` в папке `%APPDATA%\Adobe\CEP\extensions\com.fersiya.subpanel`.
