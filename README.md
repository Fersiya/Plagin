# SubPanel & PrLauncher

Комплексный набор инструментов для монтажеров и моушн-дизайнеров в **Adobe Premiere Pro** и **Adobe After Effects**: расширение **SubPanel** для работы с субтитрами и графикой + ультрабыстрый автономный лаунчер **PrLauncher**.

Поддерживаются версии Adobe CC 2019 — 2026+.

---

## ⚡ PrLauncher: Мгновенный запуск Premiere Pro

**PrLauncher** — это сверхбыстрая легковесная утилита (всего 29 КБ, чистый C# без лишних библиотек), разработанная специально для решения проблемы медленного старта Premiere Pro.

### Зачем нужен?
При обычном запуске Premiere Pro открывает тяжелый веб-интерфейс «Начальный экран» (Adobe CCX Start Screen на Chromium), загружая облачные баннеры, туториалы и сервисы. Это занимает **от 20 до 45 секунд** даже на быстрых NVMe SSD.

**PrLauncher запускает проекты за 2–3 секунды**:
- Сканирует историю недавних проектов напрямую из локального файла настроек `Adobe Premiere Pro Prefs` пользователя.
- Запускает проект аргументом в процесс Premiere Pro — Premiere мгновенно переходит к монтажу, полностью минуя стартовый экран.

### Возможности PrLauncher:
- **Мгновенный поиск**: живая фильтрация проектов по названию на лету.
- **Закрепление проектов**: кнопка ⭐ «Закрепить» держит ключевые проекты всегда наверху списка.
- **Новый проект за секунду**: кнопка «+ Новый проект» генерирует чистый оптимизированный `.prproj` без ожидания мастера создания.
- **Очистка кэша в 1 клик**: анализ и безопасная очистка папок `Media Cache Files` (`.cfa`), `Peak Files` (`.pek`) и базы данных `Media Cache`, освобождая десятки гигабайт на диске.
- **Твик начального экрана**: опция «Отключить начальный экран в Premiere Pro» переключает параметр `ShowQuickstartDialog` в настройках Premiere.
- **Тёмная тема в стиле Adobe**: современный компактный интерфейс с акцентами `#8b5cf6` и `#22d3ee`.

## 🎨 SubPanel v1.3.0: Панель субтитров для Premiere & After Effects

Универсальная панель (CEP-расширение, одна на обе программы): заготовки стилей, очистка знаков препинания, конвертер регистров, цензура мата, перенос строк и 1-клик анимации.

### Что умеет SubPanel:

1. **Заготовки стиля субтитров**:
   - Встроенные пресеты: *Классика*, *Шортс*, *МистерБист*, *ТикТок*, *Неон*, *Кино*, *Караоке*, *Минимал*.
   - Тонкая настройка: шрифт (PostScript-имя с поиском из установленных в системе), размер, цвет заливки, цвет и толщина обводки, выравнивание текста (Слева / По центру / Справа), межзнаковый интервал (Tracking), позиция по высоте.
   - Опция «Применять сразу при клике».
   - Сохранение собственных пресетов («+ Сохранить»), а также экспорт и импорт в `.json`.

2. **Регистры текста (Case Converter)**:
   - **Обычный** — без изменения.
   - **КАПС** — `ВСЕ ЗАГЛАВНЫЕ`.
   - **Предложения** — `Как в предложениях.` (первая буква после точки, `?`, `!`, переноса строки, с корректным учетом кавычек «», “”, скобок и диалоговых тире `—`).
   - **Каждое Слово** — `Каждое Слово С Заглавной` (Title Case для цепляющих заголовков).
   - **строчные** — `все строчные буквы`.

3. **Автоматический перенос строк (Line Wrap)**:
   - Ползунок «Перенос строк (CPL)»: аккуратно разбивает длинные реплики на строки по границам слов, идеально форматируя текст для вертикальных видео Shorts / Reels / TikTok.

4. **Цензура и фильтр мата (1-Click Censorship)**:
   - Кнопка «Запикать мат (Цензура)»: находит нецензурные слова в тексте (русский и английский словарь, с учетом вариантов написания через `е` и `ё`) и маскирует их стилем на выбор:
     - `***` (по длине слова, например `б****`)
     - `@#$%` (символьная плашка для соцсетей).

5. **1-клик анимации в After Effects**:
   - **Pop-Up (Отскок)**: эффектный всплывающий масштаб (0% → 115% → 100%) с плавной интерполяцией `KeyframeEase` по всем 3D-осям.
   - **Fade Up**: плавное появление снизу вверх со сглаживанием и нулевыми тангентами (без «эффекта бумеранга» и перелета траектории).
   - **Wiggle**: живое покачивание текста выражением для удержания внимания.
   - **Сброс**: чистое удаление ключевых кадров и сброс трансформаций к исходным.

6. **Удаление знаков препинания**:
   - Символы: `. , ! ? … : ; — - " «» ' ( ) [ ]`.
   - Кнопки «Все» и «Сброс» (к базовым знакам).
   - Удаление многоточий (`...`), кавычек, скобок и диалоговых тире в начале строк.

## 📊 Возможности по программам

| Функция | After Effects | Premiere Pro |
|---|---|---|
| **Стиль** | Текстовые слои: шрифт, размер, цвет, обводка, выравнивание, трекинг, регистр, позиция (включая слои с разделёнными координатами) | Графические клипы (текст/MOGRT): шрифт, размер, выравнивание, регистр |
| **Регистр и перенос** | В 1 клик для всех выделенных текстовых слоев (или всех в композиции) | В 1 клик для графических клипов на таймлайне |
| **Цензура мата** | Напрямую в слоях композиции | В графических клипах на таймлайне |
| **Анимации** | Pop-Up, Fade Up, Wiggle, Сброс ключей | Доступно в After Effects |
| **Очистка знаков** | Выделенные слои (или вся композиция), включая слои с ключами | Выделенные клипы или вся активная секвенция; для Captions — через буфер обмена или чистый SRT |

> **Примечание по Captions в Premiere Pro**: Premiere не предоставляет сторонним скриптам прямой API-доступ к редактированию дорожек подписей (Captions). Для них в панели есть два решения:
> 1. **Из буфера обмена**: выдели текст в панели «Текст», нажми Ctrl+C, нажми «Из буфера обмена» в SubPanel, затем Ctrl+V.
> 2. **SRT-файл**: нажми «SRT-файл», выбери `.srt`, панель создаст чистый файл рядом и автоматически добавит его дорожкой подписей в секвенцию.

## 🚀 Установка

1. Скачай установщик `SubPanel-Setup.exe` из раздела [Releases](https://github.com/Fersiya/Plagin/releases).
2. Запусти установщик (права администратора не требуются):
   - Он установит панель **SubPanel** в `%APPDATA%\Adobe\CEP\extensions\com.fersiya.subpanel`.
   - Установит **PrLauncher.exe** и создаст ярлыки на Рабочем столе и в меню «Пуск».
   - Автоматически настроит `PlayerDebugMode` для CSXS 9–20 в реестре Windows.
3. Открой Premiere Pro или After Effects: меню **Окно → Расширения → SubPanel**.
4. Для мгновенного запуска Premiere Pro используй ярлык **PrLauncher** на рабочем столе.

## 🛠 Сборка из исходников

### Требования:
- Windows 10/11
- PowerShell 5.1+
- NSIS (для создания инсталлятора, устанавливается через `winget install NSIS.NSIS`)
- .NET Framework 4.0+ (`csc.exe` встроен в Windows)

### Запуск сборки:
```powershell
./build.ps1
```

Скрипт автоматически:
1. Проверяет синхронизацию версий (`manifest.xml`, `main.js`, `installer.nsi`).
2. Компилирует `launcher/PrLauncher.cs` в `dist/PrLauncher.exe`.
3. Собирает установщик `dist/SubPanel-Setup.exe` через NSIS.
4. Вычисляет контрольные суммы SHA-256 в `dist/SHA256SUMS.txt`.

## 🗑 Удаление

- Через «Параметры Windows → Приложения → Установленные приложения → SubPanel».
- Либо запустите `Uninstall.exe` в папке `%APPDATA%\Adobe\CEP\extensions\com.fersiya.subpanel`.
